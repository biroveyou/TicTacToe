# Tic Tac Toe Project

Simple tic tac toe game made for the final project on the Python Essentials 1 Course on the Cisco Network Academy

The game is very straight forward and consists of a couple informations
- You choose based on the numbers in the board which position you want to insert your sign
- The player is the sign of "O" by default
- The computer is the sign of "X" by default
